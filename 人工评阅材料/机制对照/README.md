# 机制对照（4.5 节）

## 实验内容

比较三种配置在 93 个目标上的表现：

- **完整 AUCMR**：自适应区域阅读 + 完整 CREST（范围契约/缺口驱动查询/活动证据选择）+ 引用校验 + 语义核查 + DRA；
- **固定邻页**：把自适应邻页选择替换为固定顺序扩页；
- **简化 CREST**：移除范围契约、缺口规划状态、活动证据优选。

三组在 L1（证据锚定）、L2（内部一致性）、L3（需求覆盖）及三项消融指标上对比。

## 评阅口径

L1、L2 由专家团逐条评阅，L3 由三名专家（构建/复核/裁决）判定覆盖。

## 材料文件

| 文件 | 说明 |

| `汇总数据.json` | 三配置 L1/L2/L3/消融指标干净汇总 |

## 关键结果（与论文一致）

| 指标 | 完整AUCMR | 固定邻页 | 简化CREST |
|---|---:|---:|---:|
| L1 NLI-G (%) | **76.62** | 74.01 | 72.00 |
| L2 违规总数（90目标） | **107** | 118 | 134 |
| L3 宏平均 (%) | **47.80** | 39.31 | 42.35 |
| 主流程齐备衔接 (%) | 57.61 (53/92) | 63.04 (58/92) | 56.04 (51/91) |
| 分支规则通过率 (%) | **88.64** | 87.65 | 82.94 |

完整机制在证据锚定、需求覆盖、跨槽一致性与分支规则上均占优，主流程衔接略低于固定邻页（自适应阅读读到更完整证据、流程更复杂的诚实代价）。
