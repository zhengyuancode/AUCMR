# L5 Git 发布入口

最终 L5 为 AUCMR 与 PURE 既有人工文本用例的 **Agent 评价**，不是 ECHO、UCGen 复现或真人评审。已完成 10 个项目、29 对产物、174 份最终逐项评分；295 条明确义务进入完整性分母，4 条来源未决义务单列，最终 C/K/R 无 NA。

父目录的 [写作入口](../README.md)及文件索引描述的是本机完整交接包。**本次 Git 仅发布本页列明的子集**，没有发布完整 `materials/`。写作文件、结果表、原始包清单保持原字节；`package_manifest.json` 是完整本机包的清单，本目录 `manifest.json` 才是 Git 发布清单。

纳入 Git：生成与评价代码、历史执行版本及必要配置/提示/协议、最终结果表、逐项标签投影、分量来源和原文件哈希。`rating-labels.json` 保留原判断值与断言去重关系，`reference-labels.json` 保留义务 ID/状态；仅去掉原文、引句、解释文本，不改变评分。两个目标的最终 C 来自评分后来源范围裁决后的双方统一重评，K/R 沿用未变化的既有判断，不能说成所有分量来自同一次新调用。提交 HEAD 是归档版本，不是所有结果的生成版本；执行时期的冻结记录和继承清单分别保留。

只保留本机：官方源 PDF/完整提取文本、完整输入及人工对照、含大量来源引句的参照和评分、原始请求/响应、组织者私有映射、账户记录、缓存和历史失败。完整逐文件路径/哈希见 `local-archive-index.json`，已有最终材料来源索引仍见 `../artifact_manifest.json`。文件均留在原路径，没有删除、移动或另行上传；本轮未确认源材料全文的统一再分发授权。`obligations.csv` 因包含原文证据也保留本机。

`call-usage-index.json` 索引 1,603 个有请求的调用尝试目录，保留成功及历史失败状态、用量和原始文件哈希；继承的有效记录不冒充新调用。该执行器没有形成可核对的人民币费用总额，金额记为 `null`，不将请求次数或 token 用量直接转换为账单，不把未知费用写成零。

只用 Git 内材料即可运行以下标准库只读核验，无需密钥、网络或模型：

```bash
python -B docs/codex_evaluation/paper-handoff/l5/publication/verify.py
```

它从 174 份标签复算 C/K/R、29 对逐例结果、项目等权汇总与固定种子的 10,000 次 bootstrap 区间，并核对发布文件哈希。持有本机原始档案时，可加 `--with-local-archive` 验证原文件未变。

本轮还在不改写其输出文件的条件下执行了原 `scripts/verify_handoff.py`：6,300 个来源文件、3,979 处来源引句、3,147 处产物引句、一致性和稳定性检查均通过。原脚本默认会更新交接验证记录，且依赖未入 Git 的完整材料，普通克隆请使用上面的发布核验入口。

143 项相关离线测试通过（生成 8、v5 评价 125、最终范围裁决恢复 10）。测试禁止网络，将生成测试的临时产物和两个合成快照重定向至 `/tmp`，未覆盖原快照。历史材料准备脚本和两个原执行记录保留当时的绝对路径，仅用于追溯；发布核验使用仓库相对路径。恢复完整实验环境仍需索引中的本机材料，不能将本次提交理解为授权重跑。

结果同时显示 AUCMR 的 C/K 较高、R 也较高；R 越低越好，不能只报告优势维度。未修改论文或评价方法，弃用 ECHO 及其他任务改动未纳入本次提交。
