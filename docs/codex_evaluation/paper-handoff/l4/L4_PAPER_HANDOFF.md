# L4 论文写作交接总稿

整理日期：2026-11-04。仓库包位置：`docs/codex_evaluation/paper-handoff/l4/`。

本稿汇总最终采用的 L4 模型模拟从业者评价，不报告已放弃的方案或调试经过。它可独立用于方法、实验材料、结果和有效性讨论写作；具体数据文件在同目录data下，全部使用相对路径。未修改论文、实验代码、旧结果或账本，本轮没有调用评价模型。

**交接结论：原冻结批次完整完成，279次评阅、1938份有效方法评分及15份无正文记录。** 不存在未处理的原批技术失败。若论文采用后续重生成文本，则另有3个用例、9次agent评阅尚需更新，本稿不把新材料当作已评分。

本稿逐章对应独立文档，便于总控拆分使用；以下均为采用设计及实测结果。核心来源为`data/export.json`、`data/provenance.json`、`data/catalog.json`、`data/allocation.json`。


## L4 研究设计与执行协议

### 研究对象与声明

本研究使用模型模拟从业者阅读源 PDF 并评价生成用例，考察槽位正确性（PCS）和整份用例的实用性（PRC）。执行主体是 AI agent，不是真人参与者；42 个 agent 是固定模型与职业视角的任务身份，不构成42名独立专家。实验没有收集真人评分，也没有证明模型评分与真人一致。

本交接对应原冻结材料的完整评价：6个来源项目、93个用例、7种方法、42个模拟 agent、279次 agent–用例评阅、1953条方法记录。每次评阅同时展示该用例七种方法的匿名输出，使方法比较在同一评阅中配对。用例名称和参与者是固定输入，不是七个自动生成槽位的一部分。所有方法包括空输出均保留，不因结果低分删除。

七种方法的正式数据键为：`AUCMR`、`CREST w/o cross-slot check`、`LVLM-Direct`、`TextRAG-Elaborate`、`VDocRAG-Elaborate`、`ViDoRAG-Elaborate`、`ReAct-Elaborate`。它们是生成方法，不是评价模型。生成过程的技术细节由生成实验交接负责，本包不从 L4 结果反推生成参数。

### Agent 构成

| 固定视角 | 每个模型的 agent 数 | 三个模型合计 | 阅读侧重点 |
| --- | --- | --- | --- |
| 需求分析 | 4 | 12 | 任务范围、参与者目标与需求表达 |
| 软件架构 | 4 | 12 | 接口边界、系统行为及后续设计 |
| 测试与质量 | 3 | 9 | 前提、触发、分支、异常和可验证性 |
| 维护与交付 | 3 | 9 | 状态变化、可理解性和实施交接 |

每个模型14个 agent。按编号轮换上述四种视角：01、05、09、13为需求分析，02、06、10、14为软件架构，03、07、11为测试与质量，04、08、12为维护与交付。视角不改变分值、权重、严厉程度或要求得分差异。未配置虚构工作年限，也没有把每个身份伪装成独立模型。每个 agent–用例建立独立会话，不读取其他 agent 评分；同一 agent 不把之前用例的评分带入下一用例。

### 分配方法与匿名呈现

采用**模型分层的均衡不完全分配**，不称为严格 BIBD。每个用例恰由 GLM、Doubao、Qwen 各一个 agent 评价。每个模型内部9个 agent分配7个用例、5个分配6个；总计27个 agent评7例、15个评6例。因此每个 agent对应42或49份方法评分。

分配种子为 `20261029`；三个模型的分配随机数种子依次加0、1、2。按来源文档分组，组内打乱，按组大小降序分配；在仍有容量的 agent 中优先选择该文档任务最少者，其次负载最少者，随机打破并列。分配文件就是实际名单，算法描述不能替代文件。

每7个评阅生成一组随机方法排列及打乱后的循环位移，使A–G呈现位置均衡。279次评阅中每种方法出现在每个位置39或40次。它是有约束的随机平衡，不是每次完全独立的随机排列。模型收到匿名标签及用例内容，不收到方法名；主机保留标签→方法映射用于导出。内容风格仍可能泄露方法线索，不能声称双盲或完全消除识别。

### 评价顺序与保存

1. 校验来源、生成输入、分配与实现指纹，建立只读 agent–用例工作区。
2. 装载量表、职业视角、该用例七份匿名完整槽位内容、来源索引与初始检索材料。
3. 模型可请求读取材料，或提交完整评分JSON；主机执行合法工具，保留来源访问历史。
4. 对身份、标签集合、七槽字段、整数范围、空槽规则、理由类型、JSON及保存一致性进行校验。校验不判断模型理由在语义上必然正确。
5. 在既定限次内做协议纠正；成功记录评分和理由，失败记技术失败及原始响应，技术失败不转为0分。
6. 按用例与方法汇总三个模型。恢复只处理技术失败项，完整成功不重跑。最终采用结果均有来源与版本。

## 量表、空内容处理与统计口径

### 唯一评分尺度

PCS与PRC采用中文论文的分档文字。原文核查位置是上级论文项目 `samples/main-zh.tex` 中的 L4 评审问卷；该文件不属于AUCMR仓库，本包完整保留量表，因此阅读不依赖其绝对路径。下面文字也与 `eval/l4_agent/protocol.py` 的当前量表一致。

#### PCS：单槽正确性（0–3）

| 分数 | 判定标准 |
| --- | --- |
| 0 | 槽位内容错误或与该槽位要求基本无关 |
| 1 | 主要内容存在明显错误，仅有少量内容正确 |
| 2 | 总体正确，但仍存在少量错误或不准确之处 |
| 3 | 内容正确且不存在明显事实性错误 |

评分槽位固定为 `goal`（目标）、`preconditions`（前提）、`trigger`（触发）、`main_flow`（主流程）、`alternative_flow`（替代流程）、`exception_flow`（异常流程）、`postconditions`（后置条件）。每槽由模型整体判断，不按逐条断言的正确率换算。工程提示解释相邻档的区别，不新增扣分表。未检索到支持不自动等于错误，不要求每条判断独立举证后才给分。

#### PRC：整体实用性（1–5）

| 分数 | 判定标准 |
| --- | --- |
| 1 | 难以直接使用，需要基本重写 |
| 2 | 可用性较低，需要大幅修改 |
| 3 | 基本可用，但仍需要一定程度的人工修改 |
| 4 | 可用性较高，仅需要少量人工修改 |
| 5 | 能够直接支撑后续设计活动，或仅需要极少量修订 |

PRC由模型独立评价整份用例需要的实际修订幅度，不从PCS推导，不因方法相对优劣人为压分。信息已经在其他槽位出现时，PRC应考虑这种可用性；空槽数不对应固定PRC罚分，不把潜在错误后果直接等同修订工作量。没有量化“修改多少字即多少分”的额外规则。

### 空槽、全空输出和技术失败

这些是执行及缺失数据处理规则，应与论文分档文字分别报告，不能把它们都说成论文原文。

| 情况 | PCS | PRC | 结果状态 |
| --- | --- | --- | --- |
| 部分槽位为空，其余有正文 | 空槽计0；其余模型评分；仍按七槽平均 | 依据整份用例判1–5，不机械按空槽数扣分 | SCORED |
| 七槽均无可评价正文（含规范识别的拒绝输出） | 程序记录七槽0，整体PCS=0 | null，不强行当作1分 | NO_EVALUABLE_CONTENT |
| 请求、格式或基础设施失败，未获得合格结果 | null，不能计0 | null | TECHNICAL_FAILURE |

当前最终集合没有技术失败，但有5份全空生成输出，对应15条agent–方法记录。全空PCS0为操作性约定，会影响方法均值；PRC缺失是依赖输出状态的缺失，不是随机缺失。计入/排除规则和分母必须随结果披露。

### 计算公式

记用例为c，方法为m，模型/评阅为r，七槽为s。先计算单次评阅 `PCS(c,m,r)=Σ_s score(c,m,r,s)/7`，无权重、不删空槽。然后计算 `PCS(c,m)=Σ_r PCS(c,m,r)/3`。仅当三个指定模型均有完整记录才计算用例–方法均值。PRC同样对三个模型等权平均；三个中任一PRC缺失时，该用例–方法PRC为空。

主表的PCS对每种方法93个用例等权平均。PRC对该方法非空的用例–方法均值平均，并报告n。该设计各用例有三个模型，因而PCS等价于全部279个单模型方法评分的平均，但不能把279个观测当成独立用例进行推断。项目大小不等，主表不是六项目等权平均。

为避免PRC分母不同误导方法比较，附加共同支持集：七种方法PRC均非空的89个用例，所有方法在同一集合汇总。该表是敏感性/描述性对照，不替代全93例的空输出报告。另给AUCMR与每个对照方法在双方PRC均非空的集合上配对均差及胜平负；每个对照的配对分母可能不同。

### 统计解释

所有汇总使用原始精度，展示保留4位小数。SD为用例–方法均值之间的样本标准差，既不是标准误，也不是置信区间。PCS/PRC是离散有序分档，均值是约定的描述性摘要；附带中位数、范围、项目/模型/槽位分解可辅助解释。

本交接新增的分析仅为确定性描述统计，没有运行显著性检验，也未生成置信区间或事后功效。不要把描述性均值排序写成显著性结论。若另做统计推断，应保留用例内方法配对，考虑同来源项目与同模型的相关性；42个角色身份不是42名独立人类受试者。三个底层模型也不足以代表所有评价模型。

本次未实现、未采集PCmpS（单槽完整度），不能用空槽数或PCS倒推出PCmpS。模型“COMPLETE”表示协议执行完整，不能自动证明事实判断正确或真人评价有效。

数据与公式核对：`scripts/analyze.py`；原子数据：`data/export.json`；派生汇总：`data/case_method_means.csv`。

## 实际提示、来源访问与工具

### 模型看到的内容

每次初始请求由system评分约定与user结构化材料组成。user字段包括`task`、`simulated_role`、`rubric`、`slots`、`alternatives`、`required_rating_labels`、`rating_contract`、`available_tools`和`workspace`。七种匿名方法的目标用例槽位正文完整提供；整体无正文标签由程序标记并从模型待评标签集合中排除。

workspace包括来源物理页数、章节索引、每页开头最多120字符、当前来源文档内全部用例的ID/名称/参与者清单，以及初始检索正文和原页图片。**不是在首轮一次性传入所有文档的全文和所有用例的七份正文**；同文档其他用例的完整输出可由`case_outputs`按需读取。模型无其他agent评分权限。

若整份PDF提取文字总长度≤50000字符，初始提供全部提取文本；否则提供按用例选择的相关章节与邻页，最多12页、合计≤50000字符。页正文按20000字符分块；超过总字符限额的候选页会省略并记录。全文文字交付不等于所有图像交付，更不等于理解全文。

### 本地检索规则

对PDF页文字建立本地词项索引，不调用embedding模型或外部搜索。查询为用例名称和参与者，并使用固定动作词扩展：publish→report/transmit，send→transmit，open→load，record→enter，remove→delete。转小写、处理简单词尾并过滤停用词；英文数字词与中文单字参与检索。

页排序使用BM25（k1=1.2，b=0.75）及标题词覆盖加权；候选初始页来自前3个相关章节的开头最多3页，以及前4个检索命中页及其前后邻页。去重截取最多12页，再按页序交付。检索请求返回最多8条命中，每条最多800字符片段及章节ID。生成方法正文及评分不参与初始检索排名。章节边界由编号标题及大写标题启发式识别，不保证精确识别所有结构。

### 图片与MCP

初始从选中页中最多附2张具有视觉特征的原页PNG。启发式包括嵌入图像面积占比≥3%、矢量对象≥12或可提取文字少于80字符；这不是必要图表的完整检测。图片按144 DPI渲染，每张≤2000万像素，单评阅历史最多8张不同图片。追加读页可指定image=true；已在上下文中的图片无需重复附加。

使用协议版本`2025-11-25`的本地MCP stdio服务，每批一个只读服务，agent–用例工作区由不暴露给模型的句柄隔离。模型以JSON文本请求工具，由主机校验并调用MCP；不能写成三个供应商原生调用MCP。来源范围限定到当前用例所属项目，不允许读其他agent评分。

| 工具 | 必填参数 | 返回与限制 |
| --- | --- | --- |
| source_search | source_id, query | 当前源文档全文检索；query≤200字符；最多8条页片段 |
| source_page | source_id, pdf_page | 页文字；可选image、start、length；length≤20000；默认12000 |
| source_section | source_id, section_id | 章节最多4页，next_page指示续读，可选start_page |
| case_outputs | task_id | 同文档另一个用例七种匿名结果；不含评分 |

工具schema保存在`data/protocol_snapshot.json`；模型可见工具和主机管理工具分离。工具结果是历史只读材料，不是模型下一次输出的模板；文档中的指令按不可信内容处理。

## 论文写作口径与必要局限

### 可直接采用的方法段落

我们采用三种多模态语言模型构建42个模拟从业者agent，对六份源文档中的93个用例进行评价。每种模型对应14个固定职业视角身份，视角涵盖需求分析、软件架构、测试与质量、维护与交付。采用模型分层的均衡不完全分配，每个用例由三个不同模型的agent各评价一次，每个agent分配6或7个用例。各agent–用例会话相互隔离。在每次评阅中，agent依据源文档材料，同时评价七种生成方法的匿名用例输出；方法呈现顺序采用随机化的循环位移区组以平衡位置。源文档由只读MCP服务提供初始相关章节、邻页和原页图片，并允许有限轮次的全文检索与追加读取。评价使用PCS的0–3分量表和PRC的1–5分量表；PCS对七个生成槽位等权平均，PRC依据整份用例支撑后续设计所需的修订幅度独立判定。每个用例–方法组合再对三个模型等权汇总。本实验是模型模拟评价，不是真人从业者实验。

该段需配套报告空槽0、全空PCS0/PRC缺失、来源提供范围、模型参数及实际执行版本，不能只使用主体描述省略分母与局限。

### 可直接采用的结果段落

原冻结材料上的279次agent–用例评阅均完成，产生1953条方法记录，其中1938条为有效评分，15条对应五份无可评价正文的生成输出。AUCMR在93个用例上的平均PCS为2.1326，在92个可评分用例上的平均PRC为3.4384。去掉跨槽检查的消融相应为2.1234与3.3986。所有方法PRC均可评分的共同89个用例中，AUCMR的PCS和PRC均值分别为2.1477与3.4232。上述结果为所选模型与材料上的描述性观察，不能据此推断其与真人专家判断等价或统计显著优于全部方法。
