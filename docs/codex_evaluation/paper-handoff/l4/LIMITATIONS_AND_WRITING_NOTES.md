# 论文写作口径与必要局限

## 可直接采用的方法段落

我们采用三种多模态语言模型构建42个模拟从业者agent，对六份源文档中的93个用例进行评价。每种模型对应14个固定职业视角身份，视角涵盖需求分析、软件架构、测试与质量、维护与交付。采用模型分层的均衡不完全分配，每个用例由三个不同模型的agent各评价一次，每个agent分配6或7个用例。各agent–用例会话相互隔离。在每次评阅中，agent依据源文档材料，同时评价七种生成方法的匿名用例输出；方法呈现顺序采用随机化的循环位移区组以平衡位置。源文档由只读MCP服务提供初始相关章节、邻页和原页图片，并允许有限轮次的全文检索与追加读取。评价使用PCS的0–3分量表和PRC的1–5分量表；PCS对七个生成槽位等权平均，PRC依据整份用例支撑后续设计所需的修订幅度独立判定。每个用例–方法组合再对三个模型等权汇总。本实验是模型模拟评价，不是真人从业者实验。

该段需配套报告空槽0、全空PCS0/PRC缺失、来源提供范围、模型参数及实际执行版本，不能只使用主体描述省略分母与局限。

## 可直接采用的结果段落

原冻结材料上的279次agent–用例评阅均完成，产生1953条方法记录，其中1938条为有效评分，15条对应五份无可评价正文的生成输出。AUCMR在93个用例上的平均PCS为2.1326，在92个可评分用例上的平均PRC为3.4384。去掉跨槽检查的消融相应为2.1234与3.3986。所有方法PRC均可评分的共同89个用例中，AUCMR的PCS和PRC均值分别为2.1477与3.4232。上述结果为所选模型与材料上的描述性观察，不能据此推断其与真人专家判断等价或统计显著优于全部方法。

## 必须披露的局限

1. **执行主体**：42个身份共享3个底层模型，不能写成招募42名从业者、42个独立专家模型，也不能沿用人工受试者的教育、年限、疲劳或问卷时长说明。未开展真人对照或等价性验证。
2. **量表与指标**：只采集PCS、PRC；没有PCmpS。相邻分档解释用于执行，不新增固定罚分。全空PCS0/PRC缺失是操作性处理，影响均值和分母。
3. **材料覆盖**：207次初始评阅使用检索片段，只有12次会话有成功追加来源访问，不能断言所有必要页都被充分阅读。212次有图片交付不证明正确解释所有图表。
4. **匿名化边界**：方法标签被隐藏且位置均衡，但文本风格可能暴露来源。每次同时展示七种输出也可能产生上下文比较效应；提示要求按量表绝对评分，不能证明这种效应已消除。
5. **模型差异与相关性**：同源项目、同一用例内方法、同一底层模型的分数相关。角色只是阅读视角，不是随机采样的职业人群。模型间评分尺度存在可见差异。
6. **实现来源**：最终采用233/1/21/23/1项分别来自4.1.0/4.1.1/4.1.2/4.1.3/4.1.4。量表及设计一致，实际格式提示存在3种版本，恢复范围由技术失败决定而非评分挑选。仍有版本/选择机制影响，不能称全部同一新版本生成。
7. **数据范围**：本包评的是原冻结输出，四份已重生成的非空材料尚未进入L4。论文若统一改用新材料需对应补评，不能将其原空输出评分原样搬用。
8. **费用与可复现性**：费用是基于usage的估算，17笔历史费用未知保留；在线模型未来响应不保证复现。文件与响应可复核不等于语义真值已证实。

## 写作时应避免的表述

| 不宜写 | 有材料支持的写法 |
| --- | --- |
| 42位真实专家/从业者 | 三种模型构成的42个模拟从业者agent身份 |
| 严格BIBD | 模型分层、文档分散的均衡不完全分配 |
| 每例顺序完全独立随机 | 随机方法排列与循环位移区组平衡位置 |
| 所有agent都看到并完整阅读整份PDF | 有全文访问能力；按记录提供全文文字或相关片段及图片 |
| 每个agent首轮看到了所有用例的完整结果 | 首轮为当前用例七份结果与同文档用例目录，其他用例可按需调取 |
| 1953份结果全部为正常语义评分 | 1938份SCORED，15份无正文状态；技术完成279项 |
| 平均分高证明显著/专家一致 | 描述性均值较高；模型拆分与一致差异另报 |
| 所有结果均为4.1.4 | 按provenance披露实际采用记录的版本 |
| 实验准确花费122.467136元 | 已知tokens费用估算122.467136元，另有17笔未知费用 |
| 新重生成结果已完成L4 | 本包仅评原冻结输入，更新范围另列 |

本包不要求重做已完成实验，不主动增加评价指标、校准轮次或检索规则；上述边界用于准确写作。是否采用原冻结材料、是否后续处理重生成3例，由论文总控决定。
