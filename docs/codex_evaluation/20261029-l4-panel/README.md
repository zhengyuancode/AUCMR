## 固定方案

- 93 个用例，42 个模拟 agent。GLM、Doubao、Qwen 各 14 个，每个用例各分配一个，合计 279 个 agent–用例单元、1953 份方法结果评分。
- 每种模型的 9 个 agent 各评 7 例，5 个各评 6 例。总计 27 个七例区组、15 个六例区组。按来源文档分散分配，种子 `20261029`。
- 每种模型的职业视角相同：需求分析 4、软件架构 4、测试与质量 3、维护与交付 3。角色只有阅读侧重点，不设置宽严差异、虚构工作年限、不同量表或不同工具权限。
- 这是模型分层的均衡不完全分配，不是严格 BIBD。42 个 agent ID 不构成 42 个独立真人样本。同一模型、角色间的相关性必须保留在后续分析中。
- 每个单元使用隔离会话，一次同时看到该用例七种匿名方法结果。每七个单元重新随机化一个拉丁轮转块，全部 279 个单元中每种方法在各展示位置出现 39 或 40 次。不是固定顺序，也不宣称各顺序完全独立抽样。
- agent 可以查阅完整来源 PDF、原页图片、同一文档的全部用例和七种方法结果；不能读取其他 agent 评分。短文档直接提供全文文本；长文档提供页索引和按用例标题确定的初始页，原页可继续读取。材料可访问不代表已逐页阅读，实际访问保存在记录中。

## 评分与调用

保留论文 PCS 0–3 与 PRC 1–5 的分档原文，PCS 由程序对七槽取平均。模型按完整用例判断，正常可读内容给分，不设置逐断言引用门槛，不因没有检索到支持自动扣分。PRC 独立判断修订幅度，考虑信息是否已在其他槽位表达，不按空槽数量固定扣分。

沿用已接受的空槽规则：空槽 PCS 为 0，整体无正文的结果为 `NO_EVALUABLE_CONTENT`、七槽 0、PRC 不适用。技术失败的全部分数为空，不当作 0 分。原始输入、缺失信息和拒绝输出不被改写。

模型及端点沿用已保存的真实接口证据：`glm-4.6v`、`doubao-seed-2-1-pro-260915`、`qwen3.8-max-0902`。关闭思考，输出上限 8192。每个单元最多两轮本地读取工具、一次格式纠正，总共最多四次请求；不自动重试 HTTP、超时、未知费用，不按分数重新生成。全量基线 279 次，机制上限 1116 次；小试基线 9 次，上限 36 次。无正文的整组可零调用结束。

原共同账本仍为 `outputs/evaluation_campaign/budget.sqlite`。沿用平台侧限额策略，记录 usage 和估算费用，未知费用保留为未知并跳过该失败单元。价格复用 2026-10-25 已核查配置中的较高未缓存费率：GLM 输入/输出 2/6、Doubao 6/30、Qwen 12/36 元/百万 tokens。它们是记录用估算，不是供应商账单或全局费用上界。本轮不重新探测账户或模型。

格式纠正只处理完整 JSON 外层、字段及范围错误；不补造截断 JSON、不补分。达到既定机会仍失败就保存技术失败并继续后续单元。输入/实现/账本/证据完整性异常、保存失败立即停止。配置仍为 `live_authorized=false`、`binding_status=NOT_BOUND`，仅显式命令行授权允许运行已有接口观察支持的面板小试。
