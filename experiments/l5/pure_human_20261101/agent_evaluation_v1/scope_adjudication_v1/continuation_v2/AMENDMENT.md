# 来源复核排除条目兼容修订

原流程两份 Qwen 来源复核均已逐一覆盖要求的 R 编号，但同时重复列出原参照 decisions 中已经排除的草稿编号：T003 的 RC005、RB008，T009 的 RB006，且全部明确标为 EXCLUDED。严格要求列表恰好等于最终 R 编号导致技术失败，并非义务缺失或来源结论未形成。

本修订仅允许将原参照历史 decisions 中明确 exclude、且本次也明确 EXCLUDED 的额外草稿条目转入 supplementary_exclusions。所有正式编号、判断、理由不变；未知编号、额外 CONFIRMED、缺失或重复正式编号仍失败。附加条目的来源引文仍须可定位。按时间顺序恢复第一份满足条件的实际回答，不能挑选有利解释。

保留原目录、原失败 job 及请求日志。续跑目录保存完整复制和机械恢复的 provenance；不新增来源解释调用，不更换模型、不改提示。后续仍先来源裁决及冻结，再对四份匿名产物重评 C。只有本文所述行政兼容发生变化，不改变评价公式或范围裁决规则。
