# 引用格式兼容修订 v2

补充复核已产生真实回答，首版校验把产物证据误当作来源、未接入已有行号解析器，造成可恢复的格式失败。本修订不重调模型、不选取偏好的观点、不改变任何判断：成功记录原样继承；失败任务按请求时间顺序选择首份通过下列统一规则的实际回答。

- 明确匹配当前匿名产物 ID 的引用作为产物证据独立保留，不能充当共同需求依据；每项结论仍需至少一个可定位来源引用。
- 来源和产物行号严格按已发送的行目录解析，保留模型原引句、原行号及精确原文位置，不做模糊语义补写。
- 带字面省略号的引句仅可拆为同一来源中有序、逐段可确定定位的引句；明确标记为不连续引用，不能把省略部分视为已引用。
- 当输入没有待核注释时，模型额外给出的 annotation_id 不能成为原评分注释，也不能影响评分；另存 unsolicited_decisions。存在待核注释时，未知/遗漏 ID 仍失败。

所有原始调用、失败、旧冻结清单均保留。本兼容规范在机械恢复及新汇总前冻结。恢复后的结论仍按原冻结规则：两独立复核均明确诊断才解除已存在数值项的未决阻断；范围问题或分歧保留。不更改 C/K/R 数学公式。
