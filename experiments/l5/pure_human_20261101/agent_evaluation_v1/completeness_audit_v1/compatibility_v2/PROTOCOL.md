# L5 完整性未决注释复核 v1

本版本在生成和评分完成后建立，是事后、可追溯的测量核查，不是预注册评价，也不改写原评分。范围为当前 5 个 C 不可配对目标；原 29 对、全部初判、裁决、来源参照、A/B、日志均保持原文件与哈希。

## 规则与处理次序（补充调用前冻结）

1. 对全部 58 份产物、各评分角色统一扫描。若 `metric=C` 的注释仅指向冻结参照中 UNRESOLVED/EXCLUDED 的单条义务，则它仍作为来源未决保留，但不阻断仅对 CONFIRMED 义务计算的 C。这是修正分母排除后又使全指标 NA 的实现错误；不改变参照状态。未知 ID、ALL、多义务文字、全局范围、CONFIRMED 义务未决不自动豁免。
2. 其余 C 注释由 Qwen 与 DeepSeek 两个独立会话复核，使用相同提示、共同来源、冻结参照、匿名产物、原逐项覆盖判断和待核注释。不得提供方法身份、映射、生成日志或另一复核者的意见。对同目标双方均提供复核，即使另一方没有原未决注释。远程模型没有文件、shell 或工具权限。
3. 复核任务只区分：DIAGNOSTIC（已有确定的 0/.5/1 判断，注释只是遗漏/部分覆盖理由）、UNRESOLVED（尚不能确定的判定/范围问题）。不得改写覆盖值、产物、参照或主要指标。不能仅因所有字段有数字、两个评者一致或希望有完整结果就判 DIAGNOSTIC。任务范围或参照适用性问题必须保留 UNRESOLVED；不利用产物重建参照。
4. 仅当两个独立复核均明确判定 DIAGNOSTIC，且受影响义务在原记录已有数值时，汇总层将该注释改列诊断，不再阻断 C。原标签与理由不变，原记录不修改。任何分歧、未完成复核、真实歧义仍保留 NA。诊断复核不等于重新独立评分，不伪称原首判从无未决。
5. 每条复核结论给共同源的逐字引用和理由；引用采用既有规范化定位器，保存实际定位。没有注释的对照产物只做配对范围核查；若发现实质参照/公平问题，记录并保守保留该目标双方 C 的 NA，不在此版本修改参照。
6. 可恢复的只是已有数值的可计算性，不强行补分。C/K/R 公式、等权规则、项目 bootstrap（10000 次，seed=20261101）不变；保留旧结果与新结果对照，K/R 必须完全不变。未解决项写入论文局限，不能包装为真正的人类评审或严格不劣证据。

## 执行条件

仅用已授权的 AUCMR_JUNXI_DASHSCOPE_API_KEY 和 AUCMR_JUNXI_DEEPSEEK_API_KEY。模型配置继承 v5 的 qwen3.7-plus / deepseek-v4-flash，保存返回模型标识。温度 0，max_tokens 8192，thinking 禁用。角色为 annotation_review_one / annotation_review_two；每产物独立会话、固定随机队列 seed=20261101，并行最多 4。每任务最多 3 次，仅修复接口/结构/引用技术错误；失败跳过继续，失败不计零，未完成项保留 NA。无需新的评分裁决，因为两复核分歧一律保守保留原未决。

汇总前冻结模型复核决定，之后才读取私有方法映射。原先代码操作者已经接触旧汇总，不能声称整个事后修复由盲态人员发起；远程复核者仍不接收方法身份。补充审查只能提高注释分类的可追溯性，不保证参照或 Agent 判断准确。
