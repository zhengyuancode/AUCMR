# P041 最后一项技术错误的定点修复

v5已完成全部独立评分和稳定性复评，只剩P041对齐使用错误左侧ID，使裁决未完成。检查发现左侧仅C001–C005，而模型复制右侧C003–C007作为左侧。此错误涉及对齐语义，不能只删除非法ID后宣称通过。

本次仅将同一匿名产物的两套断言ID分别加LEFT_/RIGHT_前缀，再使用同供应商、同模型、同原文、同规则作新的盲态对齐。输入不含两角色标签、分数或方法身份；程序以预先固定的精确字典将返回ID投影回原ID，不推断语义对应。原始请求、命名空间响应和投影结果可追溯。随后由既定第三角色按完整需求及原产物进行实际裁决。

每角色最多4次固定技术恢复；不修改成功的58×2独立评分、其他57份裁决、源材料、参照、产物或C/K/R公式。不按质量选择重跑。该修订发生在部分结果已存在之后，不能称生成前预注册。

结果另存merged/，原v5报告及全部历史错误保留。新汇总复用原逐例、项目等权、10000次项目bootstrap及种子。已有语义未决或现行规则下的NA照实保留；技术完成不代表全部指标均无NA，也不等于真人评审或严格不劣。
