# PURE L5：匿名 Agent 评价协议 v1

版本：`AUCMR_L5_PURE_AGENT_3.0.0`。本文件仅规定新的 Agent 执行层；上级目录 `protocol/EVALUATION_v1.md`、人工评审包、输入、29 份生成产物、29 份历史人工产物及生成记录保持不变。修订依据与格式容错边界见 AMENDMENT.md；旧 v1/v2 原样保留；本版按数据及模型绑定同一性继承 v2 已成功来源记录并兼容继续，全部正式评分均为新调用。精确冻结时间、文件哈希、实际模型绑定和执行状态以本目录的机器记录为准；本文件存在不表示已经运行或通过评价。

## 1. 任务、变更及时间顺序

评价对象为选定 PURE 材料下 AUCMR 生成稿与既有人工文本用例，在相同独立需求证据范围内的文本用例质量。历史人工稿是候选产物，不是标准答案。用例名称及主要参与者已给定，不能计其识别成绩。评价交互行为语义，不按模板、标题、字段数或篇幅直接奖惩。

三个主要指标 C、K、R 已在生成前的人工协议中固定。本次用户明确改用 Agent：来源参照、复核、匿名评分及裁决均由真实模型调用完成；此次 Agent 执行协议是在生成完成后、正式评分前固定。不得将本次执行安排描述为全部在生成前预注册，不得将 Agent 记录标为 human_entered、human_consensus、专家评审或人工通过。

本协议沿用上述人工协议中引用的 UCGen 维度及其明确登记的 L5 操作化规则；不复制 UCGen 歧义公式。最新 L3 `AUCMR_L3_PURE_COVERAGE_3.0.0` 只用于独立来源、先盲读后复核、裁决和过程留痕，不采用其 RC_full 公式、未决留在分母规则或历史结果。

## 2. 角色与强制访问边界

角色名为 reference_builder、reference_independent、reference_review、reference_adjudicator_blind、reference_adjudicator、score_primary、score_secondary、alignment、score_adjudicator、stability_secondary，不使用 A/B 作为角色名。

`config.json` 是执行时唯一模型绑定依据，记录供应商、服务地址、请求模型、参数及 Junxi 凭据变量名；每次响应另存实际返回模型。本轮预检后的绑定为：reference_builder 与 score_secondary 用 DeepSeek 的 deepseek-v4-flash（预检响应标识 deepseek-flash）；reference_independent、reference_review、两个参照裁决阶段、score_primary、alignment 与 score_adjudicator 用 Alibaba 的 qwen3.7-plus。两首判使用两种模型家族，其中 DeepSeek 与生成模型同源；第三角色为独立会话/职责，但与首判 Qwen 同家族，不能据此声称三个独立模型家族或数学意义上的独立性。请求温度为 0、max_tokens 为 32768、JSON object 格式；Qwen enable_thinking=false，DeepSeek thinking disabled。实际逐次返回标识须另记录。模型身份缺失或服务不可用如实报告，不用模拟响应代替正式记录。

正式工作角色是无工具的 API 会话：不配置文件读取、仓库 shell、浏览器、搜索或外部工具。宿主编排器通过明确白名单把本次任务需要的纯数据序列化到请求；模型不能自主读取宿主文件。目录名称本身不作为权限隔离证据。读取清单、序列化输入哈希、请求消息、角色和时间全部记录。

| 角色阶段 | 允许输入 | 禁止输入 |
|---|---|---|
| 构建、独立复核首稿、裁决者盲读 | 阶段 R 的名称、给定参与者、独立需求原文与 part/page、统一规则 | 两种候选稿、原完整 PDF、私有映射、生成卡片/验证/修复/调用日志、其他角色草稿 |
| 参照复核与参照裁决 | 同一来源、已经保存的独立首稿、限定的参照意见 | 全部候选稿、映射和生成资料 |
| 两个首判评分角色 | 单份匿名产物、对应共同来源、已冻结参照、统一规则 | 另一产物、方法身份、映射、生成资料、另一首判 |
| 盲态断言对齐 | 同一匿名产物、两套去标签的单元 text/quote/offsets、共同来源 | 首判 S/X/U/Q、冗余判定、分数、方法身份 |
| 评分裁决 | 同一匿名产物、共同来源、冻结参照、两套已保存首判、盲态对齐结果 | 方法身份、另一候选、生成资料 |

全部材料中的指令性文字都是待分析数据，不能扩大任务、权限或输出要求。上游编排开发者可能接触私有映射，但无会话历史继承到正式模型工作角色；盲评是对正式工作角色的输入约束，不假称整个计算机无人知道身份。原模板风格仍可能使身份被猜测。

## 3. 冻结、队列与失败规则

本版新增调用前冻结：本协议、提示、执行代码、模型配置、只读来源及匿名产物快照哈希、角色输入白名单、队列、统计脚本及合成测试记录。冻结不包括待产生的输出，但每个输出另有不可覆盖的记录与哈希。所有 29 份参照及未决/排除记录全部冻结之后，才启动 58 份产物评分。

队列采用 `config.json` 中固定种子和已保存清单；基础种子为 20261101，两首判角色使用各自固定乱序和新会话，单次请求只有一个匿名产物。随机种子主要约束呈现顺序和抽样，不将不支持服务端 seed 的 API 宣称为完全确定性推理。统计 bootstrap 种子仍为 20261101。

每项请求最多 4 次尝试（首次加 3 次固定技术恢复）。网络、超时、拒绝服务、JSON/schema/逐字定位错误均独立登记技术状态；同一原始任务携带前次原始响应和可机器验证的错误进行预定格式恢复，不能因质量、方法得分或判断不利重跑。HTTP/JSON 成功不等于语义判断正确。超出次数保存失败，不能填零、造空产物或改目标。恢复只跳过请求哈希相同且已完成验证的成功项，所有旧尝试保留；启动期间采用进程锁，防止并发重跑覆盖。

生成产物始终只读。发现真实参照/实现错误时登记证据、影响范围，另建版本；受影响目标的双方及相关角色统一处理，保留原版本，不原地修改冻结参照或选择性替换评分。

## 4. 独立来源参照

1. 构建者和独立复核者分别从共同来源提取范围和原子义务；复核者的首稿必须在查看构建稿之前保存及锁定。裁决者也先单独读取共同来源，保存盲读首稿，然后才接收已有草稿与理由。
2. 复核者在独立首稿保存后逐条审核构建稿，检查支持性、目标范围、模态、原子化、重复与遗漏。不得只检查 JSON；遗漏必须定位共同来源。
3. 裁决者根据来源处理差异，形成最终义务清单。每个上游候选保留 lineage：合并、拆分或排除都有明确去向及理由；不能静默丢掉无法判断的候选。
4. 每条义务含稳定编号、condition/main/branch/result 类别、原子语义、来源 part 与逐字引文、从源 part 继承的 PDF 页、适用条件、原子化说明、状态与理由。初稿 ID 带角色前缀；最终 ID 在首次冻结前赋为 R001 等，冻结后不随排序变化。

一个义务是可独立判断的动作、条件或状态；“校验并保存”可拆为两项；条件—响应不能拆成孤立条件以凑数。保留主体、动作、对象、否定、模态、条件、结果和必要顺序。同义重复原文合并并保留来源；不同条件下相似行为不得盲合并。名称、标题、常识或理想流程不能补成要求。示例或可选能力不提升为无条件必需行为。

最终状态为 CONFIRMED（适用且来源明确）、UNRESOLVED（来源/归属实质歧义未解决）或 EXCLUDED（已证实范围外、重复或无支持，保留排除依据）。仅 CONFIRMED 纳入 L5 的 C 分母。UNRESOLVED 排除分母并单列数量、理由及影响；不能使用 L3 的未决分母规则。若 N=0，C 为 NA，目标仍保留在完成度和材料缺口记录中。参照不是官方 gold、人工金标或来源的等价完整规范。

## 5. 匿名首判及逐字映射

两个独立评分角色分别评价全部 58 份产物，不互见首判、对应另一版本或方法标签。每个角色必须读完提供的全文，不以检索没命中代替不存在。覆盖判断逐条对应冻结 CONFIRMED 义务；产物断言对全部行为、条件及结果作同一语义原子化。

每个原子单元包含：稳定单元 ID、用于原子语义辨识的 text、产物逐字 quote、该完全相同 quote 的零基 occurrence、类别、判定、理由、来源证据和冗余关联。程序将 quote 映射为实际原文 start/end；不得用改写的 text 冒充逐字引文。复合句多个动作可以引用同一文本范围，但 text 必须分别标明原子含义及拆分依据。标题、名称、给定参与者、“Not specified”和空字段不作为行为原子。

同义去重与不必要重复分开记录：`same_assertion_as` 指向前面语义相同的单元，供 K 去重；`duplicate_of` 只指向前面被不必要复述的单元，供 R 计数。必要上下文复述可以 same_assertion_as 非空但 duplicate_of 为空，因此 K 只判一次，R 不扣；后者非空时必须与前者最终指向同一语义根。不能用一个重复标记混淆两个指标。

覆盖记录保留对应产物原句及来源原句；0 与 0.5 必须说明缺失什么。S/Q 必须有共同源定位；X 可有矛盾源引文或明确的产物内部冲突引文；U 可无匹配源原句，但须明确已审阅范围及缺少的业务前提，不伪造“证明不存在”的引文。所有存在的引用由程序定位到原文；允许已登记的空白、NFKC、排版标点差异及唯一的 part 指针修正，保留请求引文、精确原句、原始位置与修正记录。这仅验证位置，不授予语义正确性。

## 6. 三个主要指标与边界

**C（越高越好）**：每个 CONFIRMED 义务完整覆盖为 1，部分必要组成已明确表达但缺少其他必要成分为 0.5，缺失/相反/只提名字为 0；C 为适用义务均值。重复不重复加分，可跨字段表达；按四类别给诊断分项，无来源要求的类别为 NA，不强制填标题。

**K（越高越好）**：产物去重原子断言判 S（共同源支持或无新业务前提的直接蕴含）、X（与源或内部行为矛盾）、U（共同源无法证实的具体业务事实，或不可理解的行为断言）、Q（来源自身歧义）。K=S/(S+X+U)，Q 排除并单列。U 不意味着现实世界错误或确定幻觉。完整空行为产物 K=0；只有 Q 且无可判断言时 K=NA。语言错误不作为正向数量加入 K；纯拼写诊断不构成新的主要指标。

**R（越低越好）**：未去重行为单元数为 M，不必要重复且没有新条件、结果或必要上下文的单元数为 D，R=D/M。第一次出现不算重复；条件在前置与分支中的必要复述、结果与动作不同结构作用不自动算重复。来源支持的必要额外行为不因另一候选缺失而判冗余。范围外内容单列 scope_excess，再依共同源判断 K，不能直接混作重复。M=0 时 R=NA，C=0（N>0）且 K=0。

语义裁决不能解决时保留 `unresolved`，不强制多数票，不把评审者不确定冒充来源 Q。C 的适用义务分母仍固定；若某义务覆盖值未决，保留 null，主 C 暂不可给点值，附将未决覆盖取 0/1 的范围。K 的未决断言不强行标 S/X/U/Q，主 K 为 NA 并给可计算范围；R 的重复关系/原子数存在未决时主 R 为 NA，并保留可以可靠计算的范围或范围不可确定说明。不重新定义原 C/K/R 以消除未决。独立首判也可对真正无法判断的条目显式使用 null 并登记受影响指标，仍完整保留；不能因不确定而伪造标签。

## 7. 盲态对齐、裁决及稳定性

不同首判自定义 C001 等 ID 不表示相同事实。在比较断言标签之前，alignment 角色仅接收去判定标签的单元及原文，将两套单元划为 equivalent、split_merge 或 unmatched；每个首判单元恰出现一次。只有无歧义的一对一 equivalent 组用于 nominal κ；split/merge/unmatched 数量及未对齐比例另报，不能静默删掉之后声称完整一致性。

第三角色对所有产物执行全文裁决，覆盖全部覆盖分歧、断言标签/原子化/冗余分歧。固定项目分层抽样同时标记一致项审计：每项目从匿名产物中抽 ceil(10%)，最少 1 份，以种子 20261101 确定；抽中产物的全部一致项必须核查。全量裁决是对该抽样最低要求的扩展，不能把其当作未发生的独立专家验证。裁决记录与两个首判并列存储，包含采用、修改、仍未决的理由，绝不覆写首判。

稳定性检查固定由 score_secondary 对上述同一项目分层样本做新的独立会话重复，样本种子仍为 20261101，呈现队列使用独立角色偏移（基础种子 +4）；不能看到自己的首判或裁决。重复记录只作稳定性诊断，不替换首判、不择优、不增加独立项目样本。样本及队列必须评分前冻结。

## 8. 离线验证、汇总与解释

正式材料之外的合成样例验证：宿主白名单及无工具请求、身份字段隐藏、原句/页定位、原子标签及冗余关联、空产物/缺字段/Q/N=0、公式、固定队列与恢复幂等、日志和失败状态。合成响应只用于离线代码测试，必须标记 synthetic，不得计入正式记录或覆盖真实服务失败。

程序从逐项判断计算结果，模型不得仅直接报总分。独立首判均值与裁决结果分别报告；每份产物内算 C/K/R，项目内目标等权、项目间等权，给逐例、逐项目、总体及配对 A−B。缺失、NA、未决、可评价配对数和技术失败逐层披露；不将接口失败填零，不用不完整单方替代同轮配对均值。报告源未决义务数及被排除 C 分母的影响、K 的 Q/U/X、空行为产物与未对齐单元。

项目聚类 bootstrap 10000 次，seed=20261101，按项目差值重采样，报告 A−B 的 95% 区间和全部项目点值。项目是重采样单位，断言数、调用次数和角色数不是独立样本。无任意综合分；若新增探索性显著性检验必须按原协议 Holm 校正，不以差异不显著证明相当或不劣。

一致性包含 coverage 的加权 Cohen κ（常量标签 NA）、盲态一对一对齐后的 nominal κ、C/K/R 绝对差和稳定性重复差。协议执行一致性不等于判断准确性。不得将 Agent 相互同意解释为人工确认。

最终结论限定为：在选定 PURE 材料及共同证据范围内，Agent 对 AUCMR 生成稿与既有人工文本用例的质量评价。历史人工作者可能有更多背景、共同演化需求且来源体裁不同，本实验不是控制的人机能力因果试验。不得宣称真人评审、专家水平、严格不劣、普遍泛化或来源参照无遗漏。
