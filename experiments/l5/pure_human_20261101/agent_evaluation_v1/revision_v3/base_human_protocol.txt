# L5 人工评价协议 v1（正式生成前固定）

## 任务与文献依据

比较同一目标的 A（AUCMR 根据独立需求精化）和 B（PURE 文档已有人工文本用例）。B 是待评产物，不是答案。名称、主要参与者由实验给定，不计识别成绩。评价针对共同需求中可证实的行为质量，不是通用世界知识正确性。

维度来源：Karimi & Tiwari, *UCGen: Leveraging LLMs for Automated Generation of Use Case Textual Descriptions from Requirements Specification*, ISEC 2026 Research Track, §4.3 / Table 2，PDF 7–8 页，DOI 10.1145/3796563.3796606。其引用 [26] Tiwari & Gupta (2017), IST 91:22–43，DOI 10.1016/j.infsof.2017.06.003。已取得 UCGen 全文；[26] 本轮仅核实正式书目信息与摘要，没有取得全文，不声称其具体量表已核实。

保留 completeness / correctness / redundancy 三个维度；下列原子化判定是本实验明确登记的操作化调整，不冒称 UCGen 原公式：不使用其演员识别分量、不将原始语言错误数加入越高越好的正确性、不采用括号不清的流程公式、不把新增但有依据的行为判为冗余。历史 UCGen 分数不可直接比较。

## 人员与流程

至少 2 位熟悉英文软件需求、未参与 AUCMR 生成和匿名映射的评审者；发生判定分歧时由第 3 位盲态裁决。记录各人经验、训练时间、材料访问和利益关系。先用独立合成训练例校准，不改动正式材料与主要规则。

阶段 R：评审者只查看任务名称、给定参与者、共同独立需求。为每目标建立同一份源证据清单，记录原子义务、来源 part/page/原句、适用范围、类别（条件/主行为/分支/结果）和歧义。义务必须有明确文本或直接逻辑蕴含；示例/可选项按原措辞，不变成强制事实；不能按 B 补全。不得查看任何候选 A/B。两人讨论并锁定清单及时间/哈希后，组织者才发阶段 S 产物包。该清单是独立参考标注，尚未由人建立，不伪称本轮已完成人工金标。

阶段 S：逐份随机编码文本独立评分。评审者不知道方法标签；保持两个版本间的评分独立，先完成记录再比较。原始模板仍可能留下风格线索，因此是隐藏身份的盲评尝试，不声称完全不可辨识。

必须保留初始独立评分；裁决不得覆写原记录。公布至少每目标两份独立评分和裁决后的聚合。第三人仍不接触方法映射。若实际仅有一人，须标为单评审探索结果，不能按本协议正式多评审结果报告。

## 原子化与判定规则

原子义务/产物断言：一个可独立判断的动作、条件或状态；同一句“校验并保存”拆两项，条件—响应关系保持成一个分支事实，不能拆成孤立条件来凑正确数。复合句按双方同一规则拆分。名称和给定主要参与者不作为独立得分项；参与者是否做了恰当动作仍属行为正确性。

### 完整性 C（主要指标，越高越好）

阶段 R 清单有 N 项适用、明确的原子义务。逐项 coverage 取 1（语义完整覆盖）、0.5（必要组成部分明确覆盖但仍缺一部分）、0（缺失/相反/仅提到名称）。评审者为 0.5 与 0 指出遗漏及源证据。

C = sum(coverage) / N。每义务等权；分别报告条件、主行为、分支、结果分组后再报告总体。重复描述同义事实不重复加分。允许不同字段实现同一语义；不因未使用固定标题扣分。

若独立材料没有某类内容，该类 NA，不强制补齐。若源冲突/歧义不能裁决，该义务排除分母并记歧义，不默认为任一版本错误。N=0 为材料无可评价义务，目标标不可评价，不能用 A/B 表现补造义务；保留目标及原因并报告数量。

### 来源约束的正确性 K（主要指标，越高越好）

对产物的每个去重原子行为/条件/结果断言判定：S（共同源明确支持或直接蕴含且无矛盾）、X（共同源明确矛盾/内部逻辑矛盾）、U（共同源无法证实的具体业务事实）、Q（源本身歧义）。必须填写证据 part、原句与理由。直接蕴含限于无需额外业务前提即可推出的改写或即时效果；不能用常识补出验证流程、失败消息或数值限制。文档作者可能掌握未公开知识，U 不能解释为现实世界事实必定错误。

K = S / (S+X+U)。Q 排除并独报。若 S+X+U=0：完整空产物 K=0（防止用空白取得满分）；只有源歧义而无可判断言则 K=NA 并报告。主流程、条件与分支分别给诊断分项。相同断言重复只判正确一次，重复负担由 R 捕获。

语言错误不按原始数量混入 K。只有错误造成行为不可理解/歧义时，标记“不可判定产物断言”，按 U 并说明；其余拼写语法错误单列每百词错误率作为描述性诊断，不设主检验。

### 冗余 R（主要指标，越低越好）

对未去重的全部行为语义单元计 M。D 为在同一语义位置重复、没有新条件/结果/必要上下文的多余单元数，第一次出现不计。R = D/M。条件在前置与具体分支中为理解需要而复述，或结果与动作分别起结构作用，不自动算重复。源支持的额外必要行为不因 B 没写而算冗余。与目标无关的业务细节另列 scope_excess，并在正确性中按适用源事实核查，不能无论对错都当纯重复。

M=0 时 R=NA，报告空产物及 C=0、K=0；不得通过空文档报告“零冗余优胜”。

## 空项、失败及公平条件

“Not specified”、空标题、破折号不算行为断言，也不自动加分；源要求存在而产物缺失时扣 C。B 原文的错误/矛盾/缺项/拼写保持。B 中单独出现但共同源未规定的行为按 U 处理，明确这是共同源可追溯质量，不能宣传为人工能力更差。

技术生成失败不伪造成空白质量样本。按原定 29 个目标报告完成率，质量比较仅对有完整产物且有可判证据的配对进行，同时报告未完成名单与潜在幸存偏差。不得静默换目标、删不利结果或重生成。

B 是历史文档产物，作者当时可能见过更完整背景，且需求与用例由相同作者共同演化。本实验不是同条件控制的人机生产率/能力因果实验。双方评审获得相同独立需求；生成 A 的材料减少但不得将 B 当输入。相同项目的目标相关。

## 聚合与统计

先在每份产物内按上述公式计算，再汇总独立评审者均值（裁决结果另报）；每项目内对目标等权，主汇总对项目等权。主结果为 C、K、R 的三个独立分量及 A-B 配对差，不合成一个任意加权总分。逐项目/逐例完整公开，报告词数、未覆盖义务、U/X 比例、空项与技术失败。

报告评审一致性：逐义务 coverage 的加权 Cohen κ（两人可用；常量标签时 NA），断言类别 nominal κ，量表分数绝对差；裁决不能代替一致性。小项目数下区间不稳定，采用项目聚类 bootstrap（10000 次，seed=20261101）给均值差 95% 区间，并展示全部项目点值。三个维度若进行探索性差异检验需 Holm 校正；不以 p>0.05 证明相当或不劣。

本轮没有经论证的非劣界值与功效设计，不做正式“不劣”判定。人工评分完成后只能据效应大小、区间和分项讨论在已选常规条件下质量是否接近。人工评分尚未完成时，不报告模型评分或质量比较结论。
