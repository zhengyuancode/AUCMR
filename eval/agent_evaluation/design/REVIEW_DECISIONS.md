# 第二轮意见的审核结论

审核依据为用户最后确定的两部分L3、(20).zip中的main-zh.tex、审稿意见及当前仓库可读资产。选择保持不变，不再讨论恢复全文需求穷举。

## 采纳的部分

正式主目标逐一建立有限场景；每目标一个核心成功场景及至多一个来源明确分支；只用两个目标做流程小试；对所有最终输出做内容审计；撤下旧RCR及旧数值；场景不给生成方法；复用已安排的预算对照；新Agent L4撤下无完整参照支持的PCmpS。

## 补足的关键定义

1. 正式范围写成可检查cohort，当前旧稿14主目标、七方法、98份输出；四个历史诊断目标不静默丢弃。新正文扩展主目标时同步扩展，不把14写成永久常数。
2. CP明确为已确认可保留比例，有未决同时给可能界限；不能把查找失败算幻觉，不把空输出算满分。实际共同非空集合和失败任务必须报告。
3. 核心和分支的选择次序冻结；候选按源文档默认流程及原文位置选择，不按哪个方法成功选择。
4. 场景按checkpoint核验，程序以固定优先级生成完整状态；局部正确内容不能掩盖同条件下的错误关系。
5. 所有语义由Agent完成，离线程序做结构、权限、统计和导出。评价输出不得反向修改生成方法或场景。
6. 只有两份主文档，不按断言或评分项数输出跨项目显著性。新主表给逐文档描述与同目标配对差。
7. 原500元是已有评价计划的保护上限，不能把两用例费用当正式14用例费用，也不能为省钱隐藏失败方法。
8. 运行后采纳取决于评价流程是否有效。若“效果好”指模型能可靠评价、记录可复查、预算可承担，可以据小试判断；若仅指AUCMR得分更高，不能据此选择性保留结果。

## 当前资产证据

本轮只读盘点outputs中的126个最终制品，包含98个主分析制品与28个诊断制品。主分析共有1564条最终断言，6份有效空输出，未检出本轮静态规则定义的主组结构异常。6份诊断制品有省略claims或槽位的情况，其中包含明确拒答早停，需要按协议适配例外处理，不能全部当作损坏。
