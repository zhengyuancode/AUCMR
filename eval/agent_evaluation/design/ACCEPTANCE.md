# 验收、预算与停止条件

## 1. 本设计包的静态检查

检查文件和链接存在、JSON 可解析、Schema 定义有效、18 个候选与14个主目标、七种方法、16个构造样例、种子一致、生成槽位一致、状态枚举与公式一致、模型未调用和科学结果未建立。只验证设计结构，不证明提示准确。

## 3. 模型固定样例

fixtures.json 的16项同时用于 A、B 和承担语义裁决的 C。所有首判保留。每模型至少15/16主标签正确，所有 critical_false_accept 项不得被误判 KEEP/RETAINED。格式错误或模型技术失败不得算正确。B07必须生成真实图像表格并只通过图像提供表格正文；B08必须读取两页，不能只给合成摘要。

此阈值是预设工程检查，不是外推真实数据准确率的统计保证。真实语义标签由 Agent 给出，离线代码只核对构造题的预设答案。场景选择角色另在同一构造来源上走 BUILD/VERIFY，必须不编造动作或结果、保留关键条件并有定位，不能仅测试 JSON 格式。

未通过时不进入正式评价。允许一次有记录的设计修订并对全套样例重跑，保留首次和修订版。仍未通过则停止使用该协议版本；不能反复改到 AUCMR 排名合意。

## 4. 两目标小试

JTV-01、S16-02，各七方法，全量 L3A 和各自有限场景检查。小试完成条件：

- 输入、身份和来源访问检查100%通过，无越权返回。
- 两目标均已建立经核验核心场景；分支是否建立如实记录。
- 技术任务100%完成或明确终止，终止时不把小试写成成功。
- 主模型固定样例达到要求，首评/复核/费用/访问记录完整。
- 未决率超过10%，或A/B首判一致率低于80%时触发原因分析。这两个值是工程预警，不是自动丢弃不利样本的阈值，也不是准确率证明。不能仅因为一致率高就通过语义有效性。
- 分别观察主流程、条件和图表项，记录是否出现所有模型共同接受的已知错误。发现实际参照错误必须修正版本和全部方法受影响判断。

小试用于排除流程缺陷和估算成本，不能用“AUCMR是否第一”决定进入正式实验。方法映射由协调器保管，模型运行者默认只看技术和匿名质量诊断。

## 5. 模型和费用绑定

模型 ID 延续设计 v1 的配置意图，实际可用性、底层版本和价格尚未在本轮确认。执行前从供应方官方资料完成 provider_binding.json，记录参数、图像输入、推理/输出token口径、结构输出方式、服务端限制、价格和时间。再通过固定样例验证账号实际能力。不得套用不支持的 temperature/seed，不能暗换模型。

记录评价模型与生成模型的系列及服务别名重合情况，不宣称三位Agent的错误独立。新会话只隔离历史上下文，不能消除同模型或同系列偏差。已有Qwen/Kimi/DeepSeek的设计名称不等于已取得本账号运行能力。

本设计继承500元作为整个评价计划累计费用的保守上限，不把它重新解释为每阶段500元，也不构成本轮收费授权。L3与其他层应共享账本。按80%预警，达到上限停止新增请求并保存进度。

正式规模大于两个用例，原240–440元小试估算不能当作正式预算。小试后必须按真实token和费用预估剩余工作：

- 内容任务数分别为每制品 ceil(N/6)，A、B各一份，按文件实际N计算。
- 场景建立/核验按每目标、每场景实际调用统计；有14个目标不等于只14次API请求。
- 行为评价按每制品每冻结场景，A、B各一份；另计分歧、10%一致项抽检、10%稳定性、工具循环和格式重试。
- 使用小试每任务族费用的较高分位及20%余量，分模型列预测和不确定项；不得按“2个目标费用简单乘7”忽略长度差异。

每请求预留输入、图像、输出和计费推理的可验证上界。若供应方计费无法给出可靠上界，不声称硬封顶。usage中推理已含于输出时不重复相加。预测超过剩余500元时停止正式派发，提交具体所需预算，不自动缩减方法或只评价容易内容。

当前 source、content、behavior 和 review 任务每请求最多8192输出token；需要调整上限时发布配置修订并对相关同类任务一致应用。最多1次格式/暂时故障重试，不因标签不利重试。每逻辑任务最多48次API请求，工具调用次数、API请求数和重试数分别记账。

## 6. 论文报告资格

所有主目标、方法和层均有登记；完整结果需要正式来源状态及判断均完成。无法完成的部分必须在表中显示缺失及原因，不据此宣布实验完成。只有两目标结果时，report_scope=PILOT_ONLY。

即使形式完成，若未决界限能翻转结论、A/B方向分歧明显、参照失稳或模型服务版本混杂，标记 RESULT_UNCERTAIN，只报告可支持的部分。局部范围选择与裁判偏差仍须写入局限性。

研究结果不支持AUCMR不触发质量拒收。有效负结果可以放入正文或完整补充材料，正文不得隐去后仍宣称全面优势。
