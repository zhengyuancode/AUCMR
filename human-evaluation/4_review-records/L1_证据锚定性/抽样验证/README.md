# L1 抽样人工验证（30 个目标）

## 内容

按来源文档分层抽取 30 个目标（QHeadache 3 / Microcare 5 / RLCS 6 / PeaZip 4 / JTV Auctions 6 / MIL-STD-6016B 6），对 AUCMR 与 TextRAG-Elaborate 两种配置的每条断言，由两名评阅者（A/B）独立判断来源支持与槽位适配，分歧由第三人（C）裁决。

## 数据摘要

| 口径 | AUCMR | TextRAG-Elaborate | Δ |
|---|---:|---:|---:|
| 人工裁决（30 目标） | 78.13%（468/599） | 62.98%（347/551） | +15.15pp |

- human-LLM 一致性 κ：来源支持 **0.832**、槽位适配 **0.851**（人工最终裁决 vs 模型判定）
- A/B 评阅者间分歧率：**15.7%**

## 文件

| 文件 | 说明 |
|---|---|
| `评阅者A记录.json` | 评阅者 A 对 1150 条断言的独立判定（entailment、slot_fit、理由） |
| `评阅者B记录.json` | 评阅者 B 的独立判定 |
| `裁决者C记录.json` | 最终裁决，含 `disagreement` 标记与 `note`（分歧项由 C 裁定 / 一致项沿用） |

## 口径说明

- 本目录是 **30 目标抽样验证**；93 目标的模型全量逐条记录见上级目录的 `assertion-results.json`。
- human-LLM κ 与 A/B 分歧率是不同指标，不可互换；κ 一定 ≤ 原始一致率。
