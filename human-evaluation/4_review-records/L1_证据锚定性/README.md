# L1 证据锚定性（4.3.2 节）

## 实验内容

对六份需求文档 93 个目标用例、七种配置的**候选断言**逐条评阅，判断每条断言是否同时满足：

1. **来源支持**（source support）：断言所引用的证据卡片/文本块/页面是否真正蕴含该断言内容；
2. **槽位适配**（slot fit）：断言内容是否属于它所在槽位应有的语义范围。

两项联合通过计为 NLI-G（证据锚定性得分）。

## 评阅口径

由专家团按统一标准逐条评阅，仅依据每条断言自身合法引用的证据判断，不使用同槽其他断言的引用补充证据。DRA 的自动跨槽检测与人工 L1 评阅互补，本目录只收录人工评阅结果。

**人工抽样验证**：模型对全部候选断言逐条判定来源支持与槽位适配；另按来源文档分层抽取 30 个目标，由两名评阅者独立复核、第三人裁决分歧。逐条记录见 `抽样验证/`。

## 关键结果

- AUCMR：1574 条候选断言，1206 条通过（来源支持+槽位适配），NLI-G **76.62%**。
- TextRAG-Elaborate：1781 条中 1079 条通过，NLI-G 60.58%。
- AUCMR 相对 TextRAG 高 16.04 个百分点，且候选断言少 207 条、通过断言多 127 条。

## 人工抽样验证（30 个目标）

- AUCMR 人工裁决 NLI-G **78.13%**（468/599），TextRAG-Elaborate **62.98%**（347/551），Δ **+15.15pp**。
- human-LLM 一致性 κ：来源支持 **0.832**、槽位适配 **0.851**；A/B 评阅者分歧率 **15.7%**。
