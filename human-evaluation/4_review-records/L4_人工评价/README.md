# L4 用例质量与实用性人工评阅（4.3.5 节）

## 实验内容

对七种配置生成的用例正文进行人工评分，两项指标：

1. **槽位正确性（PCS）**：0–3 分，逐槽判断内容是否正确且符合该槽语义要求；
2. **整体实用性（PRC）**：1–5 分，评估用例在需求理解、可实施性、工程度、精简度等方面的可用程度。

## 评阅口径

由 **42 名**具有需求分析、软件架构、测试与质量、维护与交付等专业背景的从业者与研究生承担，采用评阅者×目标用例的部分交叉设计，每个目标 3 人独立评阅（93 目标共 279 次），先匿名评分（不附证据卡片与中间状态）。

## 关键结果

- AUCMR：PCS **2.32**、PRC **3.63**，均为七种配置最高。
- 相对关闭跨槽检查的配置：PCS +0.12、PRC +0.13（方向一致）。
