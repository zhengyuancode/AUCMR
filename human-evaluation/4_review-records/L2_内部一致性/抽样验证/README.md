# L2 抽样人工配对验证（30 个目标）

## 内容

对 30 个目标，保留同一份组装后的用例草稿：一份原样保留（w/o DRA），一份运行 DRA（with DRA）。两份结果匿名并打乱顺序，由两名评阅者（A/B）独立检查 R1–R7 违规，分歧由第三人（C）裁决。

## 数据摘要

| 口径 | w/o DRA | with DRA | 配对减少 |
|---|---:|---:|---:|
| 人工裁决（30 目标） | 41 | 31 | −10 |

- human-LLM 一致性 κ：**0.866**
- A/B 评阅者间分歧率：**11.9%**
- 规则适用性变化：0（无"删槽位→不适用→虚算修复成功"的情形）

## 文件

| 文件 | 说明 |
|---|---|
| `评阅者A记录.json` | 评阅者 A 对 420 条规则检查的独立判定 |
| `评阅者B记录.json` | 评阅者 B 的独立判定 |
| `裁决者C记录.json` | 最终裁决，含 `applicable` 与 `disagreement` |
| `DRA同稿配对逐目标.json` | 逐目标的 w/o DRA vs with DRA 违规配对 |

- 本目录是 **30 目标人工配对验证**；89 目标的模型横向评判（120→96）见上级目录的 `L2主实验_规则违例.json`。
- 两者目标子集与评价口径不同，不可直接比绝对值，详见论文正文。
