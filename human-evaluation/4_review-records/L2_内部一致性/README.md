# L2 内部一致性（R1–R7 跨槽违规判断）

## 实验内容

L2 评价 Detail-UC 各组成部分之间的逻辑一致性。七种配置的横向比较由独立模型依据 R1–R7 七条类型化规则评判（只读最终用例、不读生成或修复日志）；DRA 的修复效果由人工配对评阅验证。违规记录含规则编号、所涉槽位、断言索引及理由。

七条规则：

| 规则 | 检查内容 |
|---|---|
| R1 | 触发事件与前置条件的对应关系 |
| R2 | 主流程与触发条件的衔接 |
| R3 | 主流程到后置条件的可达性 |
| R4 | 主要参与者在主流程中的体现 |
| R5 | 交互目标与主流程的一致性 |
| R6 | 备选流程的分支点 |
| R7 | 异常流程的退出方式 |

## L2 主实验（DRA 消融，表 13，L2 共同集 89 个目标）

启用 DRA 后，残余违规由 120 条降至 96 条（下降 20%），改善集中在 R2(−8)、R3(−6)、R6(−4)、R7(−4)，R5 为 5→5 的诚实盲点。

| 规则 | CREST w/o cross-slot check（关闭DRA） | AUCMR（完整） |
|---|---:|---:|
| R1 触发与前置条件 | 11 | 10 |
| R2 主流程与触发 | 38 | 30 |
| R3 主流程与后置条件 | 27 | 21 |
| R4 主要参与者与主流程 | 1 | 0 |
| R5 交互目标与主流程 | 5 | 5 |
| R6 备选流程分支点 | 10 | 6 |
| R7 异常流程出口 | 28 | 24 |
| **总计** | **120** | **96** |

## 人工配对验证（30 个目标）

对 30 个目标保留同一份草稿，一份原样、一份运行 DRA，匿名打乱后两名评阅者独立检查 R1–R7，第三人裁决。启用 DRA 后残余违规由 **41 条降至 31 条**；human-LLM 一致性 κ 为 **0.866**，A/B 分歧率 **11.9%**，规则适用性变化 0。逐条记录见 `抽样验证/`。
