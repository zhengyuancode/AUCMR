# 组件消融研究（4.4 节）

## 说明

本实验是论文 4.4 节的组件消融研究，**借用 L2（内部一致性）的 R1–R7 跨槽违规判断**来计算四项消融指标。L2 本身是"判断跨槽违规"的评价层（详见机制对照材料中的 L2 规则评阅记录），本目录收录的是消融研究在 6 个配置上的四项指标汇总。

## 实验内容

以完整 AUCMR 为参照，分别设置五种变体（随机槽位顺序、关闭跨槽证据卡复用、关闭区域扩展、关闭后六槽证据约束、关闭 DRA），在 93 个目标上各生成一次，按 R1–R7 七条跨槽规则逐条检查违规，报告四项消融指标：

1. 后六槽断言支持率；
2. 主流程齐备且衔接通过率（触发/主流程/后置均有内容，且 R2、R3 无违规）；
3. 主流程齐备时通过率；
4. 分支规则通过率（R6/R7 无违规）。

## 评阅口径

由专家团在 LLM 辅助预判基础上逐条复核 R1–R7 违规，并对边界案例与疑难判定重点校验。

## 材料文件

| 文件 | 说明 |
|---|---|
| `paper_tables.json`（1.0MB） | 6 配置 × 4 指标的汇总值（与论文 `tab:ablation-crest` 一致） |
| `metric_contract.json` | 指标定义契约（分子分母口径） |

## 关键结果（与论文一致）

| 配置 | 后六槽支持率 | 主流程齐备衔接 | 分支规则 |
|---|---:|---:|---:|
| 完整AUCMR | 84.09% | 55.91% (52/93) | **85.23%** (88) |
| 关闭DRA | 83.98% | 45.16% (42/93) | 68.18% (88) |

- 启用 DRA：主流程 +10.75pp、分支 +17.05pp，DRA 收益集中在流程衔接与分支规则。
- 完整组分支规则最高，主流程/后六槽略低于个别变体，为机制取舍（见论文正文）。

> 注：底层逐条 L2 违规原始记录体积约 242MB，未纳入本目录，如需可另行提供。
