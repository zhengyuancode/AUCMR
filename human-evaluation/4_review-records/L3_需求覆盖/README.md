# L3 需求覆盖（4.3.4 节）

## 实验内容

对七种配置在 93 个目标上生成的最终用例，对照**已确认参照需求项**逐项判定覆盖情况，标签为：完整覆盖（FULL）、部分覆盖（PARTIAL）、未覆盖（NOT_COVERED）、矛盾（CONTRADICTED）、来源未决（UNRESOLVED）。

参照清单共 **1367 个已确认参照需求项**（分母）+ **636 个来源未决项**（单列展示、不计入分母）。参照项仅保留"用例应表达的行为性要求"，界面布局、表单字段、协议参数等实现细节不纳入。

## 评阅口径

由三名专家承担：专家甲构建参照、专家乙独立复核覆盖判定、专家丙裁决分歧。最终采用 RECONCILED 标签。

## 材料文件

| 文件 | 说明 |
|---|---|
| `common-references93.json`（4.4MB） | 93 目标的参照清单（2003 项：1367 已确认 + 636 来源未决，含原文出处） |
| `case-results93.json`（6.5MB） | 逐目标逐需求项的覆盖标签（reconciled_judgments） |
| `combined93-summary.json` | 七配置汇总（宏/微平均、F/P/M/C 计数） |
| `metrics.json` | 逐文档宏平均等指标 |

## 关键结果

- AUCMR：完整覆盖 473、部分 284、未覆盖 597、矛盾 13，文档等权宏平均 **47.80%**，微平均 34.60%。
- ReAct-Elaborate：宏平均 45.05%（AUCMR 高 2.75 个百分点）。
