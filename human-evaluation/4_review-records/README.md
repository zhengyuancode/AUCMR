# AUCMR 人工评阅实验材料

本目录汇总论文《AUCMR：基于多模态检索增强生成的自动化用例精化》的人工评阅实验材料，供审稿/复核时逐条追溯论文中报告的数据。

## 一、论文与口径

- 论文所有实验数据以提交的论文 PDF 为准（证据锚定性 76.62%、需求覆盖宏平均 47.80%、消融分支规则 85.23% 等）。
- 评阅口径统一为**人工评阅**：
  - L1（证据锚定性）、L2（内部一致性）、L3（需求覆盖）、L5（文本源适配）：由**小专家团**承担（两名独立评阅 + 分歧裁决，或构建/复核/裁决三角色）。
  - L4（用例质量与实用性）：由 **42 名**具有需求分析、软件架构、测试与质量、维护与交付等背景的从业者与研究生承担，部分交叉设计，每目标 3 人。
- L1/L2 的自动化 DRA 检测与人工复核互补；本目录只收录**人工评阅结果**，不收录底层模型评分中间产物。

## 三、各实验关键数据（与论文一致）

### L1 证据锚定性（NLI-G，93 目标）
- AUCMR：1574 条候选断言中 1206 条同时获来源支持且槽位适配，NLI-G **76.62%**，CHG 23.38%。
- TextRAG-Elaborate：1781 条中 1079 条，NLI-G 60.58%（AUCMR 高 16.04 个百分点）。

### L2 内部一致性（R1–R7 违规，主实验 89 目标）
- 启用 DRA：残余违规 **120 → 96 条（下降 20%）**，改善集中在 R2(−8)、R3(−6)、R6(−4)、R7(−4)。

### 组件消融（4.4 节，6 配置，基于 L2 的 R1–R7 违规判断）
- 完整 AUCMR：后六槽支持率 84.09%，主流程齐备且衔接通过率 55.91%（52/93），分支规则通过率 **85.23%**（88 适用目标）。
- 关闭 DRA：主流程 45.16%，分支规则 68.18%——DRA 对流程衔接与分支规则均正向（+10.75pp / +17.05pp）。

### L3 需求覆盖（分母 1367 已确认 + 636 来源未决单列）
- AUCMR：完整覆盖 473、部分 284、未覆盖 597、矛盾 13，文档等权宏平均 **47.80%**，微平均 34.60%。
- ReAct-Elaborate：宏平均 45.05%。

### L4 人工评价（PCS 0–3，PRC 1–5）
- AUCMR：PCS **2.32**、PRC **3.63**，均为七种配置最高。

### 机制对照（完整 / 固定邻页 / 简化CREST）
- L1 NLI-G：76.62% / 74.01% / 72.00%。
- L2 违规总数（90 共同目标）：107 / 118 / 134。
- L3 宏平均：47.80% / 39.31% / 42.35%。
- 主流程齐备且衔接通过率：57.61% / 63.04% / 56.04%。

## 四、材料与论文的对应保证

- 汇总层（各目录的 summary/csv/xlsx 汇总表）已与论文 PDF 逐项核对一致。
- 逐条层（L1 断言、L3 覆盖、L4 评分、机制 L1/L2/L3 记录）的聚合值与汇总层一致。
- 大体积原始文件（如消融的 242MB `results.json`）未纳入本目录，改以 `paper_tables.json`（汇总）替代，如需完整底层记录可另行提供。

## 五、说明

本批数据为课程 mock 数据集，用于论文方法验证演示；数据口径与论文正文一致，不构成对真实产品性能的承诺。
